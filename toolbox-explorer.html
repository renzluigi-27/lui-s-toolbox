What it does

Everything you need, nothing you don't.

🔎

Search inside files

Finds text inside .xlsx, .docx, and .pdf files — not just filenames, like Windows Search.

📋

Details view browsing

Clean list view with Name, Date modified, Type, and Size — grouped and sortable.

✂️

File operations

Copy, move, rename, and delete — right-click or keyboard shortcuts, just like Explorer.

⌨️

Keyboard shortcuts

Delete, F2, Ctrl+C/X/V, Enter, F5, Backspace — all the shortcuts you already know.

📦

Portable

Single .exe file. No installer, no registry changes. Run it from anywhere, even a USB stick.

♾️

Free forever

No subscription, no premium plan, no paywalls. Built for personal use and kept free.

How it works

Simple as 1, 2, 3.

1

Download & run

Grab the .exe from GitHub Releases and run it — no installation needed.

2

Pick a folder & re-index

Browse to any folder, switch to Search mode, and click Re-index. A progress bar shows how far along it is.

3

Search everything

Search by filename or by what's actually written inside your Excel, Word, and PDF files.

Shortcuts

Works the way you already do.

🔐

Your files never leave your PC.

ToolBox Explorer runs entirely on your machine. The search index is stored locally on your computer — nothing is uploaded, nothing is sent to any server.
